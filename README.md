# KURBAN MEDICAL — Digital Business Card

Premium multilingual digital business card for **KURBAN MEDICAL** — Health & Wellness Center in Astana, Kazakhstan.

## 🌐 Languages

- 🇰🇿 Қазақша (Kazakh)
- 🇷🇺 Русский (Russian)
- 🇬🇧 English

## ✨ Features

- Mobile-first responsive design (max 450px card)
- Instant language switching with localStorage persistence
- WhatsApp booking with prefilled messages
- vCard contact download (iOS & Android compatible)
- Service cards with individual booking links
- 2GIS location integration
- SEO & Open Graph meta tags
- Glassmorphism UI accents
- Smooth animations with reduced-motion support

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript ES6+
- Google Fonts (Manrope, Inter)
